  <h2 className="text-[48px] leading-tight font-light mt-80 mb-5 text-amber-400">That's <span className="underline decoration-2 underline-offset-8 font-bold">not</span> all Folks!</h2>

<FadeIn>
  Level editing gains a command to **align selected objects** to the current camera view.
</FadeIn>

<FadeIn>
  **Lua suggestions** in the Command Bar received many fixes, and items can now be accepted by pressing
  Tab.
</FadeIn>

<FadeIn>
  The **Mover component** no longer pushes dynamic objects and now handles intersections with triggers
  on its own, removing the need to add supplemental physics components to a Unit.
</FadeIn>

<FadeIn>
  On Linux, the new `--display-server` option lets games select either the **X11 or Wayland
  backend**, with X11 remaining the default.
</FadeIn>

<FadeIn>
  **Identical physics colliders** inside Levels are now shared to reduce load times and improve
  runtime performance.
</FadeIn>

<FadeIn>
  This release also includes **more than 50 corrections** across the Editor, Runtime, Data Compiler
  and Lua API. Check out the [latest
  changelog](https://docs.crownengine.org/html/v0.64.0/changelog.html#v0-64-0) for the complete list
  of improvements and fixes.
</FadeIn>
